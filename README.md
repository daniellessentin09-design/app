# Kassensystem mit automatischem Kassenzettel

Eine einfache HTML-App für ein Kassensystem.

## Funktionen
- Artikel per Klick zum Warenkorb hinzufügen
- Automatische Erstellung und Aktualisierung des Kassenzettels
- Gesamtbetrag in Euro (deutsches Format)
- Warenkorb leeren
- Druckfunktion für den Kassenzettel
